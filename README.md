# 時間割ツール

学校の時間割を作って確かめるアプリです。今できることは次のとおりです。

- **教員の時間割(基本)を入力する**：縦が先生、横が曜日と時限の表に、授業をする学級(例：1-2)を入れます。今お使いの時間割の Excel から、まとめて読み込むこともできます。
- **学級の時間割が自動でできる**：教員の時間割から、学級ごとの時間割と、教科ごとの1週間のコマ数が自動でできます。
- **重なりや空きコマを知らせる**：同じ学級・同じ時間に違う教科が入っている、授業の入っていないコマがある、などを画面に出します。
- **週の時間割を作る**：行事予定アプリのデータファイルを読み込むと、その①〜⑥(行事で時間を入れ替えた日など)に合わせて、週ごとの教員の時間割・学級の時間割ができます。同じ先生が同じ時間に2か所の授業に入ってしまうところも知らせます。

これから、週ごとの入れ替え(出張など)や、授業の時数の予測と実績を管理する機能を足していきます(下の「これからの予定」)。

以前からある **Excel の変換・比較ツール**(`timetable_converter.html`)も、このフォルダに入っています。アプリの画面右上のリンクから開けます。

## はじめて使うとき

1. 校務共有サーバーにある `index.html` を、**Chrome または Edge** で開きます。
2. 「❓ はじめての方へ(使い方の案内)」を押すと、見本の学校を使って画面の順に使い方を案内します。
3. 「見本で試す」を押すと、架空の学校の時間割で、ひととおりの操作を試せます(見本は保存されません)。

## 使い方

1. **新規作成**：年度のはじめに1回だけ「新規作成」を押し、データファイル(.json)を作ります。保存先は、校務共有サーバーのこのアプリと同じフォルダにします。
2. **設定**：「設定」の画面で、学級数・曜日ごとの時限の数・教科を決めます。
3. **教員の時間割**：「✏ 編集する」を押して名前を入れ、表に入力します。
   - 学級の授業は「1-2」(1年2組)、2学級の合同は「3-12」(3年1組と2組)。
   - 担任の先生の行に「道徳」「学活」「総合」(または「総/学」)と書くと、その先生の学級の授業になります。担任の学級は「担当」の欄に「1-2担」のように書きます。
   - 「企画」「×」など学級名でない文字は、先生の予定として残り、学級の時間割には出ません。
   - Excel のように、範囲を選んでコピー・貼り付け、Delete で消去、Ctrl+Z で元に戻すことができます。
   - 今お使いの時間割の Excel があれば、「📥 Excel から読み込む」で先生と時間割をまとめて取り込めます(A列に「担当」の見出しがある形)。
4. **学級の時間割**：学級ごとの時間割と、1週間のコマ数を確かめます。色の意味は画面の上に出ています。
5. **週の時間割**：「週の時間割」の画面で、「✏ 編集する」を押してから「📥 行事予定を読み込む」を押し、行事予定アプリのデータファイル(.json)を選びます(行事予定のファイルは書き換えません)。
   - 読み込んだ内容はこの時間割のデータファイルに控えるので、ほかの先生は読み込み直さなくても見られます。行事予定を直したときは、もう一度読み込んでください。
   - 「前の週」「次の週」や日付で週を選び、「学級の時間割」「教員の時間割」を切り替えて見ます。
   - 行事予定の①〜⑥の「1」〜「6」は、基本の時間割の同じ曜日の何時間目の授業をするか、という意味です(例：月曜の③に「2」→ 月曜2時間目の授業)。「道」「総」「学」「音」はその教科、「行」は行事、「●」は教科が決まっていない授業、空欄は授業なしです。
   - 登校日なのに①〜⑥がまだ入っていない日は、基本の時間割どおりとして、斜めの線のマスで表示します。
6. **編集を終える**：終わったら「編集を終える」を押します。入力中も自動で保存されています。

- 「📤 Excel に書き出す」で、教員の時間割と学級の時間割を Excel に書き出せます。このファイルは「Excel から読み込む」でそのまま読み込めます(見本を表示しているときに書き出すと、見本の Excel になります)。

## データの保存場所

- 時間割のデータは、「新規作成」のときに選んだ **データファイル(.json)** に保存されます。校務共有サーバーの、このアプリと同じフォルダに置いてください。
- 先生の名前が入るので、**インターネットやクラウドのフォルダには置かないでください。**
- ブラウザには、画面の見方(最後に開いていた画面など)と、前回開いたファイルの場所だけを覚えています。データそのものは覚えていません。

## バックアップと復元

- 「設定」の画面の「データを書き出す(バックアップ)」で、今の状態をファイルに控えられます。ファイル名に日付が入ります(例：`時間割_バックアップ_2026-09-30.json`)。
- 元に戻すときは、「✏ 編集する」を押してから「データを読み込む(復元)」で、控えたファイルを選びます。今のデータは置き換わります。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 入力できない | 上の「✏ 編集する」を押してから入力してください。 |
| 「○○先生が編集中」と出る | ほかの先生が編集しています。終わるまで待ってください。15分たつと表示は消えます。 |
| 「このファイルは、あなたが開いたあとに…保存しています」と出る | ほかの先生が保存しています。「キャンセル」を押し、入力した内容を控えてから、ページを開き直してください。 |
| Excel が読み込めない | .xlsx の形式か確かめてください(.xls のときは Excel で開いて「.xlsx」で保存し直します)。A列に「担当」の見出しがあり、その次の行に 1・2・3… の時限の番号がある形が必要です。 |
| 学級の時間割に「授業なし」のコマが出る | 教員の時間割で、その学級の授業が入っていません。入力もれか、学級名の書き間違い(例：「1ー2」)がないか確かめてください。 |
| 週の時間割に「?」が出る | 行事予定の①〜⑥に、基本の時間割にない時間(例：金曜が5時限なのに「6」、土曜の授業)が入っています。行事予定の①〜⑥を確かめてください。 |
| 週の時間割で先生の重なりが出る | 行事で学年ごとに時間をずらした日に、同じ先生が2つの学年の授業に入っています。行事予定の①〜⑥か、教員の時間割を見直してください。 |
| データが消えた | 「データを読み込む(復元)」で、バックアップのファイルから戻してください。 |

## Excel の変換・比較ツール(timetable_converter.html)

時間割の Excel ファイルを読み込んで、教員ごとの時間割から **クラスごとの時間割** を作ったり、基準の時間割(正規)と出張などで入れ替えた時間割(実施日)を比べて **違うところに色を付けたり** する道具です。

1. `timetable_converter.html` を、**Chrome または Edge** で開きます(時間割アプリの画面右上のリンクからも開けます)。
2. 「🔗 まとめて実行」の枠に、時間割の Excel ファイル(.xlsx)をドロップするか、クリックして選びます。
3. 基準にする「正規」シートと、比べたいシートにチェックを入れます。
4. 実行すると、クラスごとの時間割への書き換えと、違うところの色付けが済んだ Excel ファイルができるので、保存します。

- このツールは、読み込んだ時間割を自分では保存しません(画面を閉じると消えます)。元の Excel ファイルは書き換えません。
- 画面右上のボタンで、詳しい使い方(ヘルプ)と、時間割の見本の Excel(架空の学校)を出せます。

| こんなとき | どうする |
|---|---|
| 「担当ヘッダーが見つかりません」と出る | 時間割の A 列に「担当」という見出しがあるか確認してください。 |
| 「確認が必要な項目」に見慣れない文字が出る | 時間割に新しい記号や略語が増えています。詳しい先生(開発担当)に伝えてください。 |
| .xls のファイルが読めない | Excel で開いて「.xlsx」形式で保存し直してから読み込んでください。 |
| 結果がおかしい | ヘルプの「⑦ うまくいかないときの切り分け方」を見てください。 |
